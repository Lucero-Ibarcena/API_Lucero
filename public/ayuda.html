API de registro de mascotas

Guía para usar la API. Puedes registrar perros, gatos, aves, reptiles y mascotas de cualquier otra especie.

Los datos quedan guardados aunque cierres y vuelvas a iniciar el servidor.

Qué significan las etiquetas

GET = consultar · POST = crear · PUT = actualizar · DELETE = eliminar.

El número de la ruta es el id. Por ejemplo, /mascotas/2 consulta la mascota con ID 2.

Etiqueta: Usuarios y dueños

GET /usuarios — ver todos los usuarios.
GET /usuarios/1 — ver un usuario por ID.
POST /usuarios — crear un usuario.
PUT /usuarios/1 — actualizar campos de un usuario.
DELETE /usuarios/1 — eliminar un usuario sin mascotas asociadas.

Ejemplo para crear un usuario (envíalo como JSON):

{
  "nombre": "Ana Pérez",
  "email": "ana@example.com",
  "telefono": "1122334455"
}

Etiqueta: Mascotas

GET /mascotas — ver todas las mascotas.
GET /mascotas/1 — ver una mascota por ID.
POST /mascotas — registrar una mascota.
PUT /mascotas/1 — actualizar campos de una mascota.
DELETE /mascotas/1 — eliminar una mascota.

Búsqueda recomendada: agrega filtros a /mascotas. Puedes combinar nombre, especie, raza, edad, sexo, color, tamano y usuarioId.

Por ejemplo: /mascotas?especie=Perro o /mascotas?especie=Ave&color=Verde.

También siguen disponibles las rutas de búsqueda anteriores:

  • /mascotas/nombremascota/Luna
  • /mascotas/especie/Perro
  • /mascotas/raza/Caniche
  • /mascotas/edad/3
  • /mascotas/sexo/Hembra
  • /mascotas/color/Blanco
  • /mascotas/tamaño/pequeño
  • /mascotas/dueño/Ana

Los campos obligatorios son nombre y especie. La especie es texto libre, así que no hay una lista cerrada de animales.

Crear una mascota paso a paso

  1. Crea primero el dueño con POST /usuarios.
  2. Copia el id que devuelve la respuesta.
  3. Envía ese número como usuarioId al crear la mascota con POST /mascotas.

Ejemplo de mascota:

{
  "nombre": "Kiwi",
  "especie": "Ave",
  "raza": "Cotorra",
  "edad": 1,
  "usuarioId": 1
}

Puedes probar las solicitudes con Postman o Thunder Client. Para POST y PUT, elige Body → JSON y pega los datos.
